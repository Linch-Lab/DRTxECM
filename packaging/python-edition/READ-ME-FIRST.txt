DRTxECM (Python 版) —— 使用前必讀
==================================================

這個版本跟「免安裝版」不一樣：它需要你的電腦已經安裝 Python，
但檔案小得多（約 2.6 MB 對比 126 MB），而且在某些學校或公司的電腦上，
未簽章的執行檔會被擋，這個版本反而有機會可以執行。

--------------------------------------------------
■ 怎麼啟動
--------------------------------------------------
雙擊  START-HERE.bat

就這一步。第一次啟動會自動幫你準備好一切。

--------------------------------------------------
■ 第一次啟動會發生什麼事
--------------------------------------------------
1. 自動尋找電腦裡的 Python 3.10 或 3.11
2. 在這個資料夾底下建立專用的環境（.venv），不會污染你原本的 Python
3. 自動下載並安裝需要的套件，約 150 MB，需要幾分鐘
4. 啟動程式

第 3 步只會做一次。之後再雙擊 START-HERE.bat 就是直接開啟程式。

過程中請不要關掉黑色視窗。若視窗一閃就消失，請改雙擊 DEBUG.bat。

--------------------------------------------------
■ 需要什麼
--------------------------------------------------
  Python 3.10 或 3.11
  （3.12 以上不行，原因見下方）
  約 1 GB 可用磁碟空間
  網際網路連線（只有第一次安裝需要）
  不需要系統管理員權限

--------------------------------------------------
■ 如果電腦裡沒有 Python
--------------------------------------------------
1. 到 https://www.python.org/downloads/release/python-31011/
2. 下載「Windows installer (64-bit)」
3. 安裝時，務必勾選最下方的
   「Add python.exe to PATH」
4. 安裝完成後，重新雙擊 START-HERE.bat

你不需要移除電腦裡原有的 Python 3.12 或 3.13，兩個版本可以並存。

--------------------------------------------------
■ 為什麼一定要 3.10 或 3.11
--------------------------------------------------
本程式使用的科學計算套件被鎖定在特定版本
（scipy 1.10、numpy 1.24、pandas 1.5），
這些版本沒有提供 Python 3.12 以上的安裝檔。
硬裝的話會退化成從原始碼編譯，在 Windows 上幾乎一定失敗。

--------------------------------------------------
■ 出問題的時候
--------------------------------------------------
【黑色視窗一閃就消失，或看起來什麼都沒發生】
    改雙擊 DEBUG.bat。它會讓視窗留著，並顯示程式真正的錯誤訊息。
    把畫面內容複製下來回報。

【找不到 Python】
    照上面「如果電腦裡沒有 Python」的步驟安裝 3.10。

【說我的 Python 版本不能用】
    電腦裡有 Python，但是 3.12 或 3.13。
    再裝一個 3.10 即可，舊的不需要移除。

【安裝套件失敗】
    常見原因：沒有網路、學校或公司擋住 pypi.org、防毒軟體攔阻。
    若在學校網路，PyPI 常被封鎖——這種情況請改用「免安裝版」，
    因為它不需要下載任何套件。

【建立 .venv 失敗】
    通常是磁碟空間不足、資料夾放在 OneDrive 之類的同步資料夾，
    或防毒軟體阻擋。請把整個資料夾解壓到 C:\DRTxECM 再試。

【想重新安裝一次】
    雙擊 START-HERE.bat repair
    （或直接刪除 .venv 資料夾，再雙擊 START-HERE.bat）

【只想看程式本身的錯誤訊息】
    雙擊 DEBUG.bat

--------------------------------------------------
■ 關於路徑長度
--------------------------------------------------
建議解壓到 C:\DRTxECM 這類短路徑。
Windows 的路徑上限是 260 個字元，放在很深的資料夾或 OneDrive 裡，
安裝套件時可能失敗。

--------------------------------------------------
■ 這個版本裝了什麼東西
--------------------------------------------------
  START-HERE.bat    啟動器（雙擊這個）
  DEBUG.bat         除錯模式啟動器（視窗會留著顯示錯誤）
  launch.py         程式進入點
  pyDRtTools\       程式本體
  requirements.txt  套件清單
  EIS data\         範例資料
  tutorial\         教學 notebook
  manual\           pyDRTtools 使用手冊（PDF）
  .venv\            第一次啟動後自動產生，可以整個刪掉重建
